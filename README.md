# 🧠 Valheim WikiBot — Telegram-помічник зі штучним інтелектом

## 🎯 Назва проєкту та його мета (Elevator Pitch)

**Valheim WikiBot** — це Telegram-бот, який миттєво відповідає на запитання про гру Valheim. Він використовує власну базу знань у JSON (швидкий RAG), а якщо потрібної інформації там немає — виконує пошук в інтернеті через DuckDuckGo та стискає знайдений текст до 3–4 зрозумілих речень за допомогою Gemini AI. Усе — українською мовою, без зайвої «води», реклами та довгих статей.

Раніше гравцям доводилося годинами шукати відповіді на вікі або форумах. Тепер достатньо написати питання в Telegram — і бот дасть чітку, коротку відповідь за лічені секунди.

## 👥 Цільова аудиторія

- Гравці Valheim (початківці та досвідчені), які хочуть швидко дізнатися про предмети, босів, крафт, біоми, зброю, броню, механіки гри.
- Користувачі Telegram, які цінують стислі, точні відповіді та не мають часу або бажання читати довгі статті.

## 📦 Інструкція із запуску проєкту

### 1. Склонуйте репозиторій

git clone https://github.com/OlehDe/Project_AI.git

`git checkout main6`

### 2. Створіть файл .env у кореневій папці (на рівні з bot.py)

TELEGRAM_BOT_TOKEN=ваш_токен_тут

GEMINI_API_KEY=ваш_ключ_тут

### 3. Запустити бота

`pip install -r requirements.txt`

`python bot.py`
